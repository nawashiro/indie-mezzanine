# Spec Delta

## ADDED Requirements

### Requirement: MF2エントリーとしてのルートページ

ルートページは、サービス説明を表す名前と本文を持つ単一の `h-entry` としてマークアップする SHALL。エントリー本文には、ページ内の説明とリンクを含める SHALL。

#### Scenario: MF2対応クライアントによる解析
- **WHEN** MF2対応クライアントがルートページを取得して解析する
- **THEN** クライアントはサービス名をエントリー名として検出する
- **AND** サービス説明とそのリンクをエントリー本文として検出する
