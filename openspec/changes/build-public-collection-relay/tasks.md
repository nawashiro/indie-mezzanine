# Tasks

各グループは独立した検証単位とする。実装者はその単位の検証後にだけチェックを付ける。テストは実記事ではなく固定fixtureを使う。テスト専用の内部IP許可を本番設定へ持ち込まない。

本改訂は初回スナップショットの固定とホストディレクトリでの永続化へ変更した。旧仕様の証拠では満たせないタスクは未完了へ戻した。更新・所属移動・撤回・空feed保持の実装と試験は、新しい不変性の試験へ置き換える。
